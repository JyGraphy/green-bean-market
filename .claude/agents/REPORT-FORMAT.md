# 보고서 규격 (전 직원 공통 · 엄수)

모든 에이전트는 보고서를 이 규격으로 쓴다. 사장님이 **맨 위 3줄만 읽어도 의사결정이 되도록** 하는 것이 목적이다.

## 1. 필수 구조

```markdown
# {제목}

**작성일**: YYYY-MM-DD · **담당**: {agent-id} · **신뢰도**: 상 | 중 | 하

## 📌 결론 3줄
1. (가장 중요한 사실 — 숫자 포함)
2. (두 번째)
3. (세 번째)

## ⏳ 사장님 결정 필요
- [ ] (승인/선택이 필요한 항목. 없으면 "없음")

## 본문
(표 중심. 아래 규칙 참조)

## 출처
(링크 목록 — 신뢰등급 표기)
```

## 2. 분량 상한 (토큰 절감)

| 항목 | 상한 |
|------|------|
| 결론 3줄 | 각 2줄 이내 |
| 본문 | **A4 2장 분량(약 4,000자) 이내** |
| 표 1개 | 15행 이내. 넘으면 상위 15개만 싣고 "외 N건" |
| 출처 | 8개 이내 (핵심만) |

**긴 원자료는 보고서에 붙여넣지 않는다.** 원자료는 `research/raw/`에 따로 저장하고 보고서에서는
경로만 링크한다. 보고서는 "읽는 문서", 원자료는 "쌓아두는 창고"다.

## 3. 표 우선 원칙

서술형 문단 대신 표를 쓴다. 문단은 표로 표현할 수 없는 맥락(왜 중요한가)에만 쓴다.
표에는 반드시 **숫자**가 들어가야 한다. 숫자 없는 표는 목록으로 대체한다.

## 4. 신뢰도 표기 (필수)

문서 헤더의 **신뢰도**는 아래 기준으로 정한다.

| 등급 | 조건 |
|------|------|
| **상** | 1차 출처(공식 사이트·논문 원문·공식 발표) 본문을 직접 확인 |
| **중** | 공식 발표를 인용한 매체 보도를 **2곳 이상 교차 확인** |
| **하** | 단일 매체 또는 검색 요약만으로 확인 |

개별 수치 옆에도 필요 시 표기한다:
- 확인된 값 → 그대로
- 못 읽은 값 → **"미확인"** (빈칸 금지)
- 출처끼리 다른 값 → **"출처 확인 필요"** + 양쪽 값 병기

**지어낸 숫자는 어떤 경우에도 금지.** 이 규칙 하나가 무너지면 리포트 전체가 쓸모없어진다.

## 5. 출처 표기

```markdown
- [제목](URL) — 1차 / 매체 / 검색요약
```

1차 출처가 하나도 없으면 신뢰도는 자동으로 '하'다.

## 6. 현황판 연동

보고서를 저장한 뒤:
1. `hq/agents.js`의 `LOGS` 맨 위에 한 줄 추가 (`{ date, dept, agent, text }`)
2. 해당 에이전트의 `lastWork` 갱신
3. 새 보고서 종류라면 `hq/build-artifact.py`의 `REPORT_SOURCES`에 glob 패턴 추가

이렇게 해야 현황판 보고서함에서 바로 읽을 수 있다.
