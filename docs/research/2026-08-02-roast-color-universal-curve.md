# 로스팅 색도는 프로파일·산지와 무관하게 하나의 곡선을 따른다 — "보편 색 곡선" (초록 기반)

## 1. 한 줄 요약

**아라비카 생두는 산지·가공방식·로스팅 프로파일이 아무리 달라도, 로스팅 중 색 변화가 L\*a\*b\* 색공간에서 사실상 하나의 동일한 궤적(보편 색 곡선)을 따르며, 크랙 같은 주요 이정표에서 거의 같은 색값을 보인다.**

## 3. 3줄 요약

1. 5 kg 상업용 드럼 로스터로 **7가지 서로 다른 로스팅 프로파일(총 시간은 동일, 열 적용 방식만 다름)** × **3개 산지**를 로스팅하고, 1분 간격으로 샘플을 뽑아 색도(L\*a\*b\*)를 측정했다.
2. 프로파일과 산지가 극단적으로 달랐음에도 모든 샘플의 색은 **L\*a\*b\* 공간에서 동일한 곡선 위에 올라탔고**, 컬러체인지·1차 크랙·2차 크랙에서 거의 같은 색값을 보였다.
3. 이 곡선은 다항 혼합효과 회귀(polynomial mixed-effects regression)로 모델링했고, 문헌 체계적 고찰(PRISMA 프로토콜)로 외부 검증했다. → **"라이트/미디엄/다크"를 색값 구간으로 표준화할 수 있는 근거**가 된다.

## 4. 연구 배경과 질문

- 색(color)은 산업 현장에서 로스팅 정도(roast level)를 판정하는 사실상 유일한 정량 지표다. 그러나 **"라이트 로스트", "미디엄 로스트", "다크 로스트"에 대한 업계 공통 기준이 없다.** 어떤 로스터리의 '라이트'가 다른 로스터리의 '다크'보다 어두운 경우도 생긴다(소비자 혼란).
- 기존 색도 연구는 대부분 **실험실용 소형 로스터**에서 수행돼 프로파일(시간 대비 온도 곡선) 통제가 거의 없었다. 따라서 "프로파일을 바꾸면 색 발현 경로 자체가 달라지는가?"라는 질문이 사실상 미해결이었다.
- 연구 질문: **로스팅 프로파일과 생두 산지가 달라지면, 로스팅 중 색 변화의 궤적도 달라지는가?**

## 5. 방법 (확인된 범위)

| 항목 | 내용 |
|------|------|
| 로스터 | **5 kg 상업용 배치 드럼 로스터 (Probat P5 model 2)** — 실험실 샘플로스터가 아닌 실제 상업 조건 |
| 프로파일 수 | **7종** (총 로스팅 시간은 동일하게 고정하고 열 적용 동역학만 변화) |
| 프로파일 명칭 | fast start(FS), slow start(SS), medium(MD), production(PR), exaggerated flick(EF), negative rate of rise(NRoR), extended Maillard(EM) — 자매 논문(2024, 아래 참고)과 동일 설계 |
| 로스팅 시간 | 각 로스팅 **16분** |
| 샘플링 | **1분 간격으로 채취 → 로스팅당 17개 샘플**(0분 생두 + 1~16분) |
| 생두 | ① 우간다 시피폭포(Sipi Falls) **워시드** ② 인도네시아 수마트라 **워시드** ③ 엘살바도르 아타코(Ataco) **허니** — 7개 프로파일 전체는 우간다 워시드에 적용, 나머지 2종은 부분 집합(subset)에 적용 |
| 총 샘플 | **663개 샘플 / 39회 실험 로스팅** |
| 색 측정 | 샘플을 **분쇄(ground)한 뒤** 색도계로 L\*a\*b\* 측정 (사용 기기 모델·측정 조건은 **본문 미확인**) |
| 통계 | 다항 혼합효과 회귀(polynomial mixed-effects regression) + PRISMA 프로토콜 기반 문헌 체계적 고찰로 검증 |

## 6. 핵심 결과 (확인된 수치만)

### 6-1. 주요 로스팅 이정표에서의 색값

| 로스팅 이정표 | L\* 평균 ± 표준편차 | 비고 |
|---|---|---|
| 컬러 체인지(color change) | **62.38 ± 2.6** | 프로파일·산지 무관 |
| 1차 크랙(first crack) | **29.74 ± 1.9** | 프로파일·산지 무관 |
| 2차 크랙(second crack) | **본문 미확인** | 논문은 2차 크랙에서도 색이 수렴한다고 서술하나, 검색 결과에서 정확한 수치를 확인하지 못함 |

> 주의: 위 L\* 값은 **분쇄 시료 기준**으로 보이며, 홀빈(whole bean) 측정값이나 Agtron 스케일과 직접 비교할 수 없습니다.

### 6-2. 곡선의 형태와 모델 성능

| 항목 | 확인된 값 |
|---|---|
| 색 궤적의 형태 | 로스팅이 진행되며 **L\*(명도)는 단조 감소**, **a\*(녹–적)는 상승 후 정점을 찍고 하강**, **b\*(청–황)도 유사한 아치형** |
| a\*로 L\*을 설명한 회귀 성능 | **Marginal R² = 0.934 (a\*가 L\* 분산의 93.4% 설명), p < 0.001** |
| 색차(ΔE\*) 평균 | **1.19 ± 0.76** |
| ΔE\* < 2 인 데이터 비율 | **86.48%** |
| ΔE\* < 3 인 데이터 비율 | **96.27%** |
| ΔE\* < 4 인 데이터 비율 | **99.53%** |

> ΔE\*는 두 색의 차이를 나타내는 지표로, 일반적으로 ΔE\* < 2~3은 육안으로 구별이 어려운 수준으로 해석된다(일반 색채학 관례이며 이 논문의 서술은 본문 미확인).

### 6-3. 제안된 활용

- 곡선을 **L\*a\*b\* 값 구간으로 분할해 라이트/미디엄/다크에 대응**시키면, 어떤 로스팅 샘플이든 동일한 기준으로 분류할 수 있다(논문은 이를 "가상의 예시(hypothetical example)"로 제시).
- 저자들은 이 보편 곡선을 **Agtron, Colorette 등 기존 상용 스케일로 변환하는 후속 작업**을 진행 중이라고 밝혔다.
- 2차 자료(업계 매체)에서 "CIELAB 상 로스팅 커피의 L\* 범위는 약 55(Very Light)~18(Very Dark/Espresso)"라는 서술이 보이나, **이는 논문 원문에서 확인하지 못했고 위 6-1의 컬러체인지 L\*=62.38과도 스케일이 맞지 않는다. 인용하지 말 것(본문 미확인).**

## 7. 로스터 실무 시사점 — "그래서 우리 로스팅에 뭘 바꾸나"

1. **색은 '로스팅 정도'의 지표이지 '프로파일'의 지표가 아니다.**
   프로파일 모양을 아무리 바꿔도 색은 같은 곡선 위를 움직인다. 즉 **최종 색이 같다면 "얼마나 익었는가"는 같다.** 반대로 말하면 **색만 봐서는 그 커피를 빠르게 볶았는지 느리게 볶았는지 알 수 없다.** 색을 프로파일 품질의 증거로 삼지 말고, **"도달점(roast degree) 관리 지표"로만 사용**하는 것이 맞다.

2. **품질관리(QC) 지표로서 색의 신뢰도가 올라갔다.**
   산지·가공방식이 바뀌어도 곡선이 같으므로, **하나의 색 기준(예: 1차 크랙 시점의 L\* 목표값)을 전 라인업에 공통 적용**할 수 있다. 신규 생두를 들일 때마다 색 기준을 새로 잡을 필요가 줄어든다.

3. **L\*만 측정해도 a\*·b\*를 추정할 수 있다(93.4% 설명력).**
   저가 색도계로 한 좌표만 얻어도 실무상 충분한 정보가 나온다는 뜻. **DiFluid·Colorette·Agtron 등 서로 다른 기기 간 데이터를 L\*a\*b\*로 환산해 축적해두면**, 향후 SCA 표준이 확정될 때 과거 데이터를 그대로 재활용할 수 있다.

4. **IKAWA 샘플로스팅 → 본 배치 스케일업 시 '색으로 맞추는' 방식이 정당화된다.**
   샘플로스터와 상업용 드럼은 열전달(heat transfer) 방식이 완전히 다르지만, 색 궤적이 보편적이라면 **"IKAWA에서 나온 색값을 본 배치의 목표 색값으로 삼는" 접근이 물리적으로 합당**하다. 다만 이 논문은 IKAWA를 쓰지 않았으므로(5 kg Probat 전용) **샘플로스터에 대한 직접 검증은 아니다.**

5. **마케팅·판매 표기 정비 근거.**
   SCA가 색 기반 로스팅 레벨 표준을 준비 중(2025년 10월 백서 발간, 전문가 그룹 검토 예정)이므로, **지금부터 상품 페이지에 "라이트/미디엄" 대신 실측 색값을 병기**해두면 표준 도입 시 선제 대응이 된다. 생두 유통 관점에서도 "이 생두는 L\*=OO에서 가장 좋다" 식의 **정량적 로스팅 가이드**를 붙이면 차별화 요소가 된다.

6. **주의: 색이 같아도 맛은 같지 않다.**
   이 논문은 **색의 수렴**만 보여준다. 같은 색에 도달한 서로 다른 프로파일이 같은 맛을 낸다는 주장은 이 논문에 **없다**. (오히려 자매 논문에서 프로파일에 따라 특정 시점의 적정산도가 2배까지 차이났다 — `2026-08-02-roast-profile-titratable-acidity.md` 참조)

## 8. 한계 및 미확인 사항

- **생두 3종뿐**이며 7개 프로파일 전체를 적용한 건 우간다 워시드 1종. 나머지 2종은 부분 집합만 적용 → **산지 일반화의 근거는 상대적으로 약하다.**
- **아라비카 한정.** 로부스타(Coffea canephora)에 동일 곡선이 적용되는지는 검증되지 않았다(제목부터 "arabica").
- **로스팅 시간 16분 고정.** IKAWA 샘플로스팅(통상 5~9분)이나 초고속 로스팅에서 동일한 곡선을 따르는지 **본문 미확인**.
- 색 측정이 **분쇄 시료 기준**으로 보이며, 홀빈 측정 시의 값·오차는 미확인. 홀빈/분쇄 색차(자주 쓰는 'roast delta')에 대한 언급 여부도 미확인.
- 색도계 기기 모델, 조명·관측 조건(D65/10° 등), 측정 반복 수는 **본문 미확인**.
- **관능(sensory) 평가가 없다.** 색 곡선과 컵 품질의 관계는 이 논문의 범위 밖.
- 2차 크랙에서의 구체적 L\*a\*b\* 값, 다항 회귀식의 계수는 **본문 미확인** → 전문 접근이 열리면 최우선 확인 대상.
- 2025년 10월 정오표가 존재하므로, **원문을 읽을 때는 반드시 정오표를 함께 볼 것**(Figure 4 축 라벨, 참고문헌 53–55 인용).
