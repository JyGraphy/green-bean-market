# 📥 논문 전문 수집 대기열

`scripts/paper_fetch.py --queue` 가 이 파일의 `- [ ] PMC번호` 줄을 읽어 **전문(full text)**을 받아
`vault/raw/papers/fulltext/` 에 저장한다. GitHub Actions("리서치 자료 수집")에서 실행된다.

- 오픈액세스 논문만 받아진다(저작권). 구독 저널은 초록만 가능.
- PMCID는 europepmc.org 검색이나 `paper_fetch.py --search "<검색어>"` 로 찾는다.
- 받아진 뒤에는 `coffee-research-translator` 가 전문을 한글로 완역한다.
