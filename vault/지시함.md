# 📮 지시함

사장님이 직원에게 직접 일을 시키는 곳. **옵시디언에서 이 파일에 한 줄 적으면 끝.**

작성법: `- [ ] @담당 지시내용` — 급하면 뒤에 `!급함`을 붙인다.

| 태그 | 담당 | 하는 일 | 비용 |
|------|------|---------|------|
| `@옥션` | auction-reporter | COE·BOP 등 각국 옥션 전체 랏 결과 | 중 |
| `@발굴` | store-scout | 새 생두 쇼핑몰 찾기 (보고만) | 소 |
| `@온보딩` | new-store-onboarder | 승인한 공급사 실제 추가 | 중 |
| `@논문` | coffee-research-translator | 커피 논문 **전문** 한글 완역 | 중 |
| `@프로파일` | roast-profile-collector | 프로파일 수집 → **로스팅 AI 학습** → 결과 보고 | 중 |
| `@데이터` | data-validator | 상품 데이터 검증 | **0~소** |
| `@스크래퍼` | scraper-checker | 스크래퍼 규칙 점검 | **0~소** |
| `@프론트` | frontend-reviewer | 화면 변경 리뷰 | 소 |
| `@정리` | (메인 세션) | raw를 wiki로 정리 | 소 |

> `@데이터`·`@스크래퍼`는 `scripts/qa_report.py`가 먼저 돌아 **토큰 0으로 처리**되고,
> 스크립트가 못 잡는 게 있을 때만 AI가 붙는다.

**지시를 전달하는 법**: 저에게 이렇게 한마디만 하세요 → **"지시함 확인해줘"**
**자동 확인은 현재 없습니다** — 지시를 넣으신 뒤 반드시 저에게 한마디 해주세요.
(2026-08-03 기준: 기존 09시/18시 자동 루틴은 삭제됐고, 매시간 자동 확인은 도구 권한 문제로
설정하지 못한 상태입니다. 해결되면 이 문구를 갱신합니다.)

```bash
python3 scripts/orders.py            # 대기 중인 지시 확인 (토큰 0)
python3 scripts/orders.py --dispatch # 실행 계획 출력
```
